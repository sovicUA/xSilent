Який голос лишаємо на озвучення?

Зразки синтезованого мовлення для озвучення сповіщень. Усі — гонг + голос, вирівняні по гучності, той самий текст. Три напрями: A — Google, B1 — Azure, B3 — ElevenLabs.

«Це зразок обраного голосу озвучення.»

Послухайте й напишіть, який голос звучить найкраще для хвилини мовчання.

A · Google — швидко й безкоштовно

    B1 · Azure Neural — безкоштовно в межах квоти

      B3 · ElevenLabs — нативні україномовні голоси

        A — Google SeaNet: ~0.5 дня роботи, безкоштовно, лише жіночий голос, перший синтез потребує мережі, далі кеш офлайн.

        B1 — Azure та B3 — ElevenLabs: ~2–3 дні роботи кожен. Обидві статі, синтез онлайн один раз → кеш офлайн. Потребують дозволу INTERNET та оновлення політики приватності. Azure — безкоштовно в межах квоти (500K символів/міс); ElevenLabs — платний акаунт, голоси нативні з бібліотеки спільноти.
